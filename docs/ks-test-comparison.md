# KS 시험표 비교

기존 KCS 대응 판단과 분리된 참고 분석이다. 담당자 판정, 검토의견, 수정 본문,
DOCX 내보내기를 변경하지 않는다. 시험표의 시험방법은 KS 코드로 참조하고,
현장 빈도·시료 수·등급·합격기준은 별도로 검토하기 위한 기능이다.

## 범위

- KS 번호가 세 번째 열에 있는 5열 시험표 행을 인식한다. 임의 표를 이 구조로 추측하지 않는다.
- 공식 e나라표준인증 상세 페이지에서 현행 판과 개정/확인 날짜를 읽는다.
- 그 페이지에서 제공하는 기계가독 원문만 정상 공개 경로로 조회한다.
- 원문의 번호·판·시행일이 일치하는 경우에만 GPT 입력으로 사용한다.
- 기계가독 원문에 섞인 AI 추천 문서는 표준 내용이 아니므로 제거한다.
- 원문을 읽지 못한 경우 `unavailable` 또는 `viewer_only`다. KS 대응 없음이 아니다.
- KS 약기/범위, 상동 등은 전체 대체를 확정하지 않는다.

2026-09-11 실조회: KS L 4201은 기계가독 원문 비교 가능. KS F 4004와
KS F 4002는 현행 판 조회와 고시 원문 열람 링크 제공, 자동 본문 비교는 미지원.
이는 해당 KS가 없다는 뜻이 아니다. 기계가독 서비스는 시범 서비스이며
정확한 고시 내용은 공식 원문에서 최종 확인한다. 원문 이용조건을 준수하며
KS 전문의 재배포·판매용 데이터셋을 생성하지 않는다.

## 동작

- `GET /api/projects/{pid}/clauses/{cid}`의 `ks_test_comparison`은 저장 결과만 읽는다.
- `POST .../clauses/{cid}/ks-test-comparison`은 원문 확인/비교를 실행한다.
- `refresh: true`는 공식 원문을 다시 확인하지만 같은 입력·같은 판·같은 본문·같은
  모델의 저장 결과가 있으면 GPT를 재호출하지 않는다.
- 신규 문서의 기존 GPT 상세분석 작업에서도 해당 시험표를 자동 처리한다.
- 기존 문서는 KS 패널에서 비교를 실행할 수 있다. KS 실패로 기존 KCS 분석을 폐기하지 않는다.
- 확인 날짜가 오늘보다 이전이면 갱신 필요를 표시한다. 외부 확인은 GET에서 실행하지 않는다.
- 원문 또는 편집 본문 변경 시 저장 결과를 무효화한다.
- 결과는 기존 `app_metadata`에 `ks_test:{clause_id}`로 저장한다. KS 전문은 저장하지 않는다.
- GPT의 각 원문 필드 포함 여부와 인용 절·인용문 존재를 검증한다. 검증 실패는 `unconfirmed`다.
- 필드 분류명이 아닌 실제 원문 조건을 비교한다. '10일', '공사개시전 1회' 등을 일반
  품질기준으로 대응시키는 판정은 수치·단위 근거와 설명의 모순을 점검해 보류한다.
- 코드 참조형 제안문에도 빈도·등급·수치는 원문 그대로 남는다. 차이가 표시된 조건은
  채택 전에 담당자가 조정해야 한다. 이 제안은 자동 적용되지 않는다.

## 확인

`server/tests/test_ks_test_comparison.py`는 공식 판 검증, AI 추천문 제거,
비대응/미확인 구분, 원문 필드 누락, 인용문 조작, 캐시, 판 갱신, 원문 변경,
기존 판정 보존, 보관 문서 차단을 검증한다. 테스트의 표준 본문은 가상 예문이다.
